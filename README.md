Interactive personal developer portfolio, engineering showcase, and research CV for **Mansur Rustamov** (Law Student at Tashkent State University of Law & AI/Software Engineer).

Built using **Next.js 14**, **TypeScript**, **Once UI Design System**, and **MDX** for dynamic case studies and technical articles.

---

## 🎨 Key Features

- **⚡ Server-Side & Static Generation**: Next.js App Router with lightning-fast route transitions and optimal Core Web Vitals.
- **🌗 Dark / Light Mode & Theming**: Integrated design tokens with fluid typography and glassmorphic micro-interactions.
- **📝 MDX Content System**: Built-in support for markdown case studies, interactive legal-tech project breakdowns, and blogs.
- **📱 Fully Responsive**: Tailored layout supporting ultra-wide monitors down to compact mobile displays.

---

## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/mansurxongemini/developer-portfolio.git
cd developer-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
